# MERN Development

A collection of frontend practice assignments covering the foundations of HTML and CSS. The exercises build from simple HTML documents into structured, accessible, responsive layouts using modern CSS techniques.

## Contents

| Assignment | Topics and examples |
| --- | --- |
| `assignment01` | Git initialization, repository commands, and terminal output |
| `assignment02` | Terminal-based practice output |
| `assignment03` | HTML document structure, headings, and text formatting |
| `assignment04` | HTML attributes, page layout, and corrected attendance markup |
| `assignment05` | Home page, portfolio pages, and images |
| `assignment06` | Lists and content pages: shopping list, FAQ, and canteen menu |
| `assignment07` | About-me pages and page composition |
| `assignment08` | Forms, choices, and required fields |
| `assignment09` | Accessible marks tables and average calculations |
| `assignment10` | Inline, internal, and linked CSS |
| `assignment11` | CSS variables, design tokens, and CSS units |
| `assignment12` | Box model, cards, and scrolling behavior |
| `assignment13` | Flexbox layouts, navigation, centering, and wrapping cards |
| `assignment14` | CSS Grid, dashboard areas, and image galleries |
| `assignment15` | Mobile-first design, responsive images, and responsive text |

## Project Structure

Each assignment is kept in its own folder. HTML files can be opened independently in a browser, while shared stylesheets and image assets remain beside the exercises that use them.

```text
Mern-Development/
├── assignment01/
├── assignment02/
├── assignment03/
├── ...
├── assignment15/
└── README.md
```

## How to Run

No build tools or dependencies are required.

1. Clone or download the repository.
2. Open any assignment folder.
3. Open an `.html` file directly in a web browser.

For a smoother development workflow, open the repository in VS Code and use a local server extension such as **Live Server**. This is optional; the pages are self-contained and do not require a backend.

## Skills Practiced

- Writing valid HTML document structure
- Using semantic elements, links, lists, tables, and forms
- Improving form and table accessibility
- Applying inline, internal, and external CSS
- Understanding the CSS cascade, selectors, variables, units, and box model
- Building layouts with Flexbox and CSS Grid
- Creating mobile-first and responsive pages
- Organizing images and supporting assets

## Status

This repository is an ongoing learning lab. Later assignments can be extended into larger frontend projects as the MERN stack is introduced.
